# Lore Master — SillyTavern extension

**จัดการ lorebook คู่กับหน้า World Info ของ ST** ทำมาให้ใช้บนมือถือเป็นหลัก หน้าตาอ่านง่าย ช่องกรอกใหญ่ และอธิบายทุกช่องเป็นภาษาไทย

ตอนแรกหน้า World Info เดิมของ ST อยู่ครบเหมือนเดิม Lore Master เปิดจากทางของมันเอง ถ้าอยากใช้ตัวนี้ตัวเดียวไปเลย เลือก **ใช้แทน** ได้ในหน้าตั้งค่า (ดู [ใช้คู่กันหรือใช้แทน](#ใช้คู่กันหรือใช้แทน))

มี 3 ส่วน (แถบเมนูด้านล่าง):

- **เล่ม**: ดูทุกเล่ม เปิดแก้ทีละเอนทรี และผูกเล่มกับการ์ด แชท หรือ Global
- **ตรวจ & รวม**: นำเข้า lorebook จากเว็บอื่น (JanitorAI ก่อน) รวมหลายเล่มเป็นเล่มเดียว หาสาเหตุที่ติดทีละหลายสิบเอนทรีแล้วซ่อม
- **ตั้งค่า**: API สำหรับ AI, ค่าการสแกน World Info ของ ST อธิบายเป็นภาษาคน, ใช้คู่กับหรือแทนหน้า World Info เดิม, ทางเข้า และหน้าตา

มี **เบรกฉุกเฉิน** กัน lorebook ที่ดึงเอนทรีเป็นร้อย ๆ ตัวจน ST ค้าง (ดู [เบรกฉุกเฉิน](#เบรกฉุกเฉิน))

และมี **AI ช่วย** 3 อย่าง (ดู [เครื่องมือ AI](#เครื่องมือ-ai)): คิดคีย์ภาษาไทย · อภิธานชื่อเฉพาะ · ย่อเนื้อหาที่ยาว

## ติดตั้ง

Extensions → Install extension → วาง URL ของ repo นี้

### อัปเดต

Extensions → Manage extensions → อัปเดต Lore Master แล้วกด **โหลดเวอร์ชันล่าสุด** ในแผง Extensions → Lore Master

เบราว์เซอร์ (โดยเฉพาะ ST ที่เปิดจากไอคอนบนหน้าโฮมของ iPhone) มักเก็บไฟล์เก่าไว้ แม้อัปเดตแล้วก็ยังรันตัวเดิม ปุ่ม **โหลดเวอร์ชันล่าสุด** จะดึงไฟล์ทุกไฟล์ของ Lore Master จากเซิร์ฟเวอร์ใหม่แล้วโหลดหน้าใหม่ให้

- **ดูเวอร์ชัน:** ชื่อในแผง Extensions มีเลขเวอร์ชันที่**รันอยู่จริง**ต่อท้าย ใต้ปุ่มมีบรรทัดบอกว่าบนเซิร์ฟเวอร์ติดตั้งเวอร์ชันไหนไว้
- **ถ้าสองเลขไม่ตรงกัน** จะขึ้นแจ้งเตือน แตะแจ้งเตือนนั้นเพื่อโหลดใหม่ได้เลย
- **เช็คได้อีกที่:** หน้า ตั้งค่า → สถานะ ของ Lore Master มีปุ่ม **เช็คเวอร์ชัน** และ **โหลดเวอร์ชันล่าสุด** เหมือนกัน

## เล่ม

**รายการเล่ม**
- ด้านบนคือเล่มที่ **ใช้อยู่ตอนนี้** กับแชทที่เปิด มีป้ายบอกว่าเป็น 💬 เล่มของแชท · 👤 เล่มหลักของการ์ด · 📎 เล่มเสริม · 🎭 Persona · 🌐 Global
- ทุกเล่มบอกจำนวนเอนทรี โทเคนรวม และจำนวนที่ติดตลอด
- ปุ่ม ⋯ ของแต่ละเล่ม:
  - ตรวจหาปัญหา
  - เปิด/ปิด Global
  - ตั้งเป็นเล่มหลักหรือเล่มเสริมของการ์ด
  - ผูกกับแชทนี้
  - เปลี่ยนชื่อ: ลิงก์ทุกที่ (Global การ์ด แชท persona) เปลี่ยนตามให้
  - ทำสำเนา · รวมกับเล่มอื่น · ดาวน์โหลด .json · ลบ
- ปุ่ม **+** มี 3 อย่าง: สร้างเล่มเปล่า · นำเข้าไฟล์ (ตรวจก่อนบันทึก) · รวมหลายเล่ม

**ในเล่ม**
- **ชิปด้านบน** แตะเพื่อผูก/ถอดเล่มนี้กับ Global การ์ด หรือแชทได้ทันที
- **ค้นหา** ทั้งชื่อ คีย์ และเนื้อหา
- **เรียง** ตามลำดับในเล่ม · ชื่อ · order · ความยาว
- **ตัวกรอง**: ติดเมื่อเจอคีย์ · ติดตลอด · ปิดอยู่ · มีคำเตือน · ไม่มีคีย์ไทย
- **การ์ดเอนทรี** มีแถบสีบอกสถานะ 🟢 เจอคีย์ · 🔵 ติดตลอด · ⚪ ปิด, คีย์, ตำแหน่ง, order, โทเคน, ⚠ คำเตือน และสวิตช์เปิด/ปิด
- **เลือกหลายรายการ** (ปุ่ม ☑ ที่หัวหน้า) แล้วทำทีเดียวได้: เปิด/ปิด · ติดตลอด/เจอคีย์ · ตำแหน่ง · order · กันลูกโซ่ · คัดลอก/ย้ายไปเล่มอื่น · ลบ

**แก้เอนทรี** บันทึกเองระหว่างพิมพ์ มีสถานะบอกที่หัวหน้า

| หมวด | |
|---|---|
| ชื่อ | ไว้ให้เราหาเจอ |
| ติดเมื่อไหร่ | เจอคีย์ / ติดตลอด / ปิด, คีย์เป็นชิป (Enter หรือ , เพื่อเพิ่ม), คีย์รองพร้อมเงื่อนไขเป็นภาษาคน, **บอกทันทีว่าข้อความล่าสุดในแชททำให้เอนทรีนี้ติดไหม** |
| คำเตือนคีย์ | ชื่อตัวละครหลัก (ติดทุกเทิร์น), ตัวเลข, สั้นเกิน, คำทั่วไป, คำไทยสั้นที่ไปติดกลางคำอื่น, regex ผิด |
| เนื้อหา | ช่องขยายตามข้อความ นับตัวอักษรและโทเคนด้วย tokenizer ของ ST |
| ใส่ตรงไหน | ทุกตำแหน่งพร้อมคำอธิบาย, ความลึกและบทบาท (@D), ชื่อ Outlet, order |
| ขั้นสูง | ความน่าจะเป็น · Inclusion group · Sticky/Cooldown/Delay · ลูกโซ่ · การสแกน (ความลึก ตัวพิมพ์ ทั้งคำ, สแกนในคำอธิบาย/persona/scenario) · ใช้เฉพาะบางตัวละคร · ทำงานเฉพาะตอน (swipe, continue …) · ไม่นับงบ · Vector · Automation ID |

ปุ่ม ˄ ˅ ที่หัวหน้าใช้ไปเอนทรีก่อน/ถัดไป ส่วน ⋯ มีทำสำเนา · เลื่อนขึ้น/ลง · คัดลอก/ย้ายไปเล่มอื่น · ลบ

## ตรวจ & รวม

สำหรับ lorebook ที่ import มาจากเว็บอื่นซึ่งไม่ได้เขียนมาเพื่อ ST เลยติดทีละหลายสิบเอนทรี ติดผิดเรื่อง หรือไม่ติดเลย

ตัวอย่างจากบอทบน JanitorAI ที่มี 3 เล่ม รวม 160 เอนทรี ทดสอบด้วยข้อความในแชท 2 ข้อความ:

| | ก่อนซ่อม | หลังซ่อม |
|---|---|---|
| เอนทรีที่ติด | 40 | 6 |
| โทเคน | ≈ 7,800 | ≈ 1,400 |

ทำเป็น 4 ขั้น:
1. **เลือกเล่ม** ไฟล์ .json (ของ ST, JanitorAI, character_book หรือการ์ด) หรือการ์ด .png (หลายไฟล์ได้) · เล่มใน ST · เล่มทั้งหมดของการ์ดที่เปิดอยู่ ถ้าเลือกหลายเล่มจะรวมเป็นเล่มเดียว ไฟล์จากเว็บอื่นไม่บอกตำแหน่งใน prompt จะให้เลือกเอง
2. **ตรวจ** แสดงปัญหาเรียงตามความด่วน พร้อมเหตุผล ติ๊กเลือกได้ทีละรายการ แล้วกดซ่อมทีละข้อหรือทั้งหมด กดย้อนได้ ถ้ามีแชทเปิดอยู่ จะเทียบให้ดูว่าข้อความล่าสุดทำให้ติดกี่ตัว ก่อนซ่อมกับตอนนี้
3. **ทดสอบ** วางข้อความดูว่าอะไรติดเพราะคีย์ไหน เทียบก่อน/หลัง ไม่เรียก API
4. **บันทึก** เป็นเล่มใหม่หรือเขียนทับเล่มเดิม (สำรองไว้ก่อน) และทำได้อีก 3 อย่าง:
   - ตั้งเป็นเล่มหลักของการ์ด เวลา export การ์ด เล่มนี้จะติดไปด้วย คนที่ได้การ์ดไปใช้ได้เลยโดยไม่ต้องลง Lore Master
   - ถอดเล่มที่รวมไปแล้วออกจากการ์ด จะได้ไม่ติดซ้ำ 2 ที่
   - จำกัดจำนวนเอนทรีต่อเทิร์น

### อ่านผลการตรวจยังไง

ด้านบนของหน้าตรวจมีกล่อง **อ่านก่อนซ่อม** บอกลำดับที่แนะนำ ทุกข้อจะมีป้ายบอกว่าเป็นแบบไหน และบอก 3 อย่าง: **ทำไม** · **ถ้าซ่อม** จะเปลี่ยนอะไร · **ข้อควรรู้** (ข้อเสีย)

- **ไม่แตะคีย์** (ลูกโซ่ ติดตลอด เรื่องซ้ำ รูปแบบคีย์ คำสั่งเว็บอื่น)
  - ซ่อมได้เลยโดยไม่เสียอะไร
  - ปุ่ม 🛡 **ไม่แตะคีย์** ซ่อมเฉพาะกลุ่มนี้ทีเดียว
  - ข้อลูกโซ่ข้อเดียวก็แก้การติดทีละหลายสิบเอนทรีได้เกือบหมด
- **แก้คีย์** (ชื่อตัวละครหลัก คำทั่วไป ชื่อชนกัน)
  - การลบคีย์มีข้อเสียเสมอ คือแชทพูดคำนั้นแล้วเอนทรีจะไม่ติด
  - ติ๊กไว้ให้เฉพาะที่ค่อนข้างปลอดภัย ที่เหลือเลือกเอง
- **รวมทุกข้อที่ติ๊กแล้วจะเหลือคีย์อะไร** บอกไว้ทุกบรรทัดที่ลบคีย์ เพราะหลายข้ออาจลบคีย์ของเอนทรีเดียวกัน
  - ถ้ารวมแล้วจะไม่เหลือคีย์เลย Lore Master จะเก็บคีย์สุดท้ายไว้ให้ เอนทรียังติดได้
- **"คีย์ที่อยู่ในเนื้อหาของเอนทรีอื่นจำนวนมาก"** เป็นผลของลูกโซ่ ซ่อมข้อลูกโซ่แล้วข้อนี้จะหายไปเอง เลยไม่ติ๊กไว้ให้

### สิ่งที่ตรวจ

| ปัญหา | ซ่อมยังไง |
|---|---|
| **คีย์ที่โผล่แทบทุกข้อความ**: ชื่อตัวละครหลัก (ทั้งชื่อเต็มและชื่อเดียว), `{{user}}` และคำที่อยู่ในเนื้อหาเกือบทุกเอนทรี ST ใส่ชื่อคนพูดไว้หน้าทุกข้อความ คีย์พวกนี้จึงติดทุกเทิร์น | ลบคีย์นั้น ถ้าเป็นคีย์เดียวที่มีอยู่ จะไม่ติ๊กไว้ให้ |

| **คีย์ชนกับชื่อของเอนทรีอื่น** เช่น "Mercer" ของตัวร้ายไปติดตอนพูดถึง "Eli Mercer" | ติ๊กให้ลบเฉพาะที่เป็นนามสกุล ส่วนชื่อต้นให้เลือกเอง |
| **ติดตลอด (constant) มากเกินไป** | เปลี่ยนเป็นติดเมื่อเจอคีย์ เหลือตัวเล็กสุดไว้ 1 ตัว |
| **ไม่มีคีย์** เลยไม่มีวันติด | ใช้ชื่อเอนทรีเป็นคีย์ |
| **คีย์รูปแบบเพี้ยน** เช่น `"a, b"` อยู่ในช่องเดียว มีเครื่องหมายคำพูดติดมา หรือซ้ำกัน | แยกคีย์ ตัดเครื่องหมาย และลบตัวซ้ำ |
| **คำสั่งของเว็บอื่น** เช่น `@@depth` ของ RisuAI, `{{#if}}` หรือสคริปต์ทริกเกอร์ของ JanitorAI | ลบบรรทัด `@@` ให้ ส่วนที่เหลือบอกว่าต้องแก้เอง |
| **เอนทรียาวเกิน 500 โทเคน** และ **ไม่มีคีย์ภาษาไทย** | ใช้เครื่องมือ AI ด้านล่าง: ย่อเนื้อหา · คิดคีย์ไทย |

ตัวทดสอบจำลองแบบที่ติดมากที่สุด: ไม่นับ probability, inclusion group และงบโทเคน ของจริงอาจติดน้อยกว่านี้ ส่วนนับโทเคนเป็นค่าประมาณ ถ้าอยากเห็นของจริงตอนเจน ใช้ [Lore Lens](https://github.com/inathael-58/SillyTavern-LoreLens)

## จำกัดจำนวนเอนทรีต่อเทิร์น

เปิดได้ตอนบันทึกในหน้า ตรวจ & รวม หรือตั้งภายหลังในหน้า **ตั้งค่า** ของ Lore Master

ถ้าเล่มนั้นติดเกินจำนวนที่ตั้ง จะตัดตัวที่ติดทีหลังทิ้งก่อน ST เรียงเอนทรีจาก order สูงไปต่ำ แล้วค่อยต่อด้วยตัวที่ติดจากลูกโซ่ ตัวที่ติดทีหลังจึงสำคัญน้อยที่สุด ส่วนเอนทรี constant จะไม่ถูกตัด

ระบบนี้ทำงานเฉพาะเครื่องที่ลง Lore Master เล่มที่ส่งต่อให้คนอื่นใช้ได้ตามปกติ

ต้องใช้ ST รุ่นที่มี event `WORLDINFO_SCAN_DONE`

## เบรกฉุกเฉิน

บางบอทใส่ lorebook มาใหญ่มาก และเนื้อหาของแต่ละเอนทรีมีชื่อของเอนทรีอื่นเต็มไปหมด ตัวอย่างจริงคือการ์ดที่มี 542 เอนทรี (≈780,000 โทเคน):

- แค่ข้อความแรกก็ทำให้ติด 14 เอนทรี
- จากนั้นลูกโซ่ (recursion) จะลากตามมาอีกเป็นร้อยตัว รวมเกือบ 470 เอนทรี ≈760,000 โทเคน
- ST ต้องนับโทเคนของข้อความหลายเมกะไบต์ซ้ำไปซ้ำมา เลยค้างตั้งแต่ข้อความแรก ไม่ว่าคอมจะแรงแค่ไหน

เบรกฉุกเฉิน (เปิดไว้ตั้งแต่แรก) ทำงานทุกเทิร์น กับทุกเล่ม:

1. **ก่อน ST สแกน** ดูว่าแชทล่าสุดจะทำให้ติดกี่เอนทรี ถ้าเกินที่ตั้ง จะตัดตัวที่ order ต่ำสุดออกจากรอบนี้ (เอนทรีติดตลอดไม่ถูกตัด)
2. **หลังสแกนแต่ละรอบ** ดูว่าลูกโซ่รอบถัดไปจะดึงมาอีกเท่าไหร่ ถ้ารวมแล้วเกินที่ตั้ง จะหยุดลูกโซ่ไว้ตรงนั้น ST จึงไม่ต้องทำรอบที่ทำให้ค้าง

ทั้งหมดใช้เวลาราว 30 มิลลิวินาทีแม้เป็นเล่ม 542 เอนทรี และไม่แก้ไฟล์เล่มเลย (ตัดเฉพาะของที่ส่งให้การสแกนรอบนั้น)

- **ค่าเริ่มต้น:** ไม่เกิน 40 เอนทรี และ 25,000 โทเคนต่อเทิร์น แก้ได้ในหน้าตั้งค่า
- **เมื่อเบรกทำงาน** จะขึ้นแจ้งเตือนว่าเล่มไหนจะดึงกี่เอนทรีกี่โทเคน และเหลือเท่าไหร่ แตะแจ้งเตือนเพื่อเปิดเล่มนั้นในหน้า ตรวจ & รวม
- **เปิดแชทที่ใช้เล่มใหญ่มาก** (เกิน 300 เอนทรี หรือ 100,000 โทเคน) จะเตือนครั้งเดียว และแตะเพื่อตรวจได้เหมือนกัน
- **ต้องใช้ ST รุ่นที่มี event** `WORLDINFO_ENTRIES_LOADED` และ `WORLDINFO_SCAN_DONE`
- **หน้า ตั้งค่า → สถานะ** บอกว่า:
  - Lore Master เชื่อมกับการสแกนของ ST ได้ไหม
  - การสแกนล่าสุดติดกี่เอนทรี กี่โทเคน จากเล่มไหน และเบรกทำงานไหม
  - Context ที่เหลือให้ prompt และงบ lorebook ตอนนี้เป็นกี่โทเคน
  - ใช้เช็คได้เวลาเจอ "Mandatory prompts exceed the context size"

เบรกช่วยให้เล่นต่อได้ แต่ควรซ่อมเล่มด้วย ในหน้า ตรวจ & รวม:

- ข้อ "ลูกโซ่ recursion" จะบอกว่าเล่มนี้ลากกันได้ถึงกี่ตัว แก้ด้วยการเปิด Prevent further recursion ทั้งเล่ม
- ใช้เครื่องมือ "ย่อเนื้อหาที่ยาว" กับเอนทรีที่ยาวเป็นหมื่นโทเคนต่อไป

**ตรวจการ์ดก่อน import ได้:** หน้า ตรวจ & รวม → เลือกไฟล์ → เลือกการ์ด `.png` ได้เลย Lore Master จะอ่าน lorebook ในการ์ดออกมาให้ตรวจและซ่อมก่อน แล้วค่อยบันทึกเป็นเล่ม

## เครื่องมือ AI

### ตั้ง API (หน้า ตั้งค่า → AI)

- **เรียงลำดับ API เองได้** จะเป็น API หลักของ ST หรือ Connection Profile ก็ได้ ตัวแรกล่ม ไม่ตอบในเวลาที่ตั้ง หรือตอบมาใช้ไม่ได้ จะลองตัวถัดไปเอง
- **ตั้งแยกตามงานได้** แท็บ **ชุดหลัก** · **คิดคีย์ไทย** · **ย่อเนื้อหา** ปิดสวิตช์ "ใช้ชุดหลัก" ในแท็บของงานนั้นเพื่อตั้งรายการของตัวเอง แนะนำ:
  - **คิดคีย์ไทย:** โมเดลเล็กอย่าง flash-lite ก่อน ตามด้วย flash
  - **ย่อเนื้อหา:** flash ก่อน เพราะต้องเก็บรายละเอียดให้ครบ
- **นับครั้งที่ใช้วันนี้** ข้างแต่ละ API (เฉพาะเครื่องนี้ นับทุกครั้งที่ลอง รวมที่ล้มเหลว) ไว้ดูโควต้าของ API ฟรี
- **ใช้ชุดเดียวกับ Memory Hub:** คัดลอกลำดับ API ของ Memory Hub มาเป็นชุดหลัก
- **ทดสอบ:** ทดสอบรายการของแท็บที่เปิดอยู่

### คิดคีย์ภาษาไทย

แชทภาษาไทยจะไม่เจอคีย์ภาษาอังกฤษ Lore Master ส่ง**เฉพาะชื่อเฉพาะ**ของแต่ละเอนทรีให้ AI ไม่ต้องส่งทั้งเนื้อหา:

- **ชื่อที่ส่ง:** ชื่อที่เป็นคีย์แบบตัวพิมพ์ใหญ่ เช่น "Garrick Voss" หรือ "Weld"
- **ไม่ส่ง:** คีย์บรรยายตัวเล็ก ตัวเลข ตัวย่อ คำทั่วไป และชื่อเอนทรีที่เป็นหัวข้อ เช่น "Season Structure"
- **ชื่อซ้ำ:** ถามครั้งเดียว เช่น "Marc Ellis" อยู่ 3 เอนทรี
- **ชื่อต้น:** แยกมาจากคำตอบของชื่อเต็ม ไม่ต้องถามแยก เช่น "Marc" ได้มาจาก "Marc Ellis" = "มาร์ก เอลลิส"
- **ชื่อที่เคยถามแล้ว:** จำไว้ในเบราว์เซอร์ ไม่ถามอีก ทั้งตอนกดใหม่ เล่มอื่นของบอทเดียวกัน และปุ่ม ✨ ในหน้าแก้เอนทรี ล้างได้ในหน้าตั้งค่า
- **บอกก่อนเริ่ม:** มีกี่ชื่อ จำไว้แล้วกี่ชื่อ จะใช้ราวกี่ครั้ง แล้วค่อยกดเริ่ม ส่งครั้งละ 80 ชื่อ
  - การ์ด 160 เอนทรีใช้ราว 3 ครั้ง การ์ด 540 เอนทรีราว 6 ครั้ง
- **ถ้า AI ตอบตกบางชื่อ** ถามซ้ำเฉพาะชื่อนั้น ถ้าชุดใหญ่ล้มเหลว จะแบ่งครึ่งแล้วลองใหม่

AI ถอดเสียง**ตามภาษาต้นทางของชื่อ** (เยอรมัน ฝรั่งเศส อิตาลี ญี่ปุ่น…) ตามหลักราชบัณฑิตฯ เป็นตัวแรก และให้ **แบบอ่านอังกฤษ** เป็นตัวเลือก เช่น Michelangelo → มีเกลันเจโล / ไมเคิล แองเจโล ชื่อดังที่คนไทยใช้ตัวสะกดอื่นกันมาก จะเอาตัวที่ใช้กันขึ้นก่อน

ตารางให้เลือกแยกเป็นกลุ่ม: **ตามภาษาต้นทาง** (บอกภาษา) · **อ่านแบบอังกฤษ** · **แปล** (ชื่อสถานที่ ทีม องค์กร **ไม่ติ๊กไว้ให้** เลือกเพิ่มเอง)

- **⭐ ข้างชิป** เลือกตัวสะกดที่จะใช้ในอภิธาน ตัวที่ติด ⭐ จะเป็นคีย์ไทยตัวแรกของเอนทรี
- **ในหน้าแก้เอนทรี** ชิปคีย์ไทยก็มี ⭐ ให้แตะเปลี่ยนได้เหมือนกัน

ทุกคีย์ที่เสนอจะตรวจก่อนแล้วขึ้น ⚠ ถ้าเป็นคำไทยสั้นที่ไปติดกลางคำอื่น (เช่น ยา) หรือไปติดตอนพูดถึงเอนทรีอื่น (เช่น "มาร์ค" อยู่ใน "มาร์คัส") คีย์ที่มี ⚠ จะไม่ติ๊กไว้ให้

ใช้ได้ 2 ที่:

- **ทีละเอนทรี:** หน้าแก้เอนทรี → ✨ **ให้ AI เสนอคีย์ไทย**
  - ส่งเนื้อหาไปด้วย จึงได้ชื่อเล่นหรือคำเรียกจากเนื้อหาด้วย
  - ชื่อที่เคยถามแล้วไม่เสียโควต้า กด **ถามใหม่** ถ้าอยากได้คำตอบใหม่
- **ทั้งเล่ม:** เมนู ⋯ ของเล่ม → **ให้ AI คิดคีย์ไทยทั้งเล่ม** หรือหน้า ตรวจ & รวม → เครื่องมือ AI
  - ยังไม่แก้ไฟล์จริงจนกว่าจะกดบันทึก
  - ระหว่างทำงานกด **หยุด** ได้ ผลที่ได้มาแล้วยังอยู่

### อภิธานชื่อเฉพาะ

เอนทรี `📖 อภิธานชื่อ (Lore Master)` บอกโมเดลว่าชื่อไหนสะกดไทยยังไง เช่น `Cody Dawson = โคดี้ ดอว์สัน` โมเดลจะได้สะกดเหมือนเดิมทุกเทิร์น และตรงกับคีย์ ความจำจึงเชื่อมกันได้

- **ทำมาจากอะไร:** สร้างจากคีย์ไทยตัวแรกของแต่ละเอนทรี อยากเปลี่ยนตัวสะกด ให้ย้ายคีย์ที่ต้องการไปไว้หน้าสุด แล้วกดอัปเดต
- **สร้าง/อัปเดตได้ที่ไหน:** เมนู ⋯ ของเล่ม · หน้า ตรวจ & รวม · หรือติ๊ก "สร้างอภิธานไปด้วย" ตอนเพิ่มคีย์ไทยทั้งเล่ม
- **เป็นเอนทรีธรรมดา** แบบติดตลอด คนที่ได้การ์ดหรือเล่มไปแต่ไม่ได้ลง Lore Master ก็ใช้ได้ (ได้ทั้งรายการทุกเทิร์น)
- **โหมดประหยัด** (เปิดไว้ตั้งแต่แรก ปิดได้ในหน้าตั้งค่า) ใช้กับเครื่องที่ลง Lore Master:
  - ตอนเล่นจะเอาเอนทรีอภิธานออก แล้วส่งเฉพาะชื่อที่โผล่ในแชท 6 ข้อความล่าสุด หรือชื่อของเอนทรีที่ติดในเทิร์นนั้น
  - ต้องใช้ ST รุ่นที่มี event `WORLDINFO_ENTRIES_LOADED`

### ย่อเนื้อหาที่ยาว

สำหรับเอนทรีที่เขียนแบบบรรยายยาว ๆ AI จะตัดคำบรรยายฟุ่มเฟือย มุก และเรื่องซ้ำออก เหลือเป็นข้อ ๆ ใต้หัวข้อเดิม แต่เก็บข้อเท็จจริงไว้ครบ ทั้งชื่อ ความสัมพันธ์ รูปร่าง ความสามารถ จุดอ่อน และความลับ

- **ภาษาเดิม:** ไม่แปล และเก็บ `{{char}}` `{{user}}` ไว้ ถ้าคำตอบของ AI ทำมาโรหายไป หรือไม่สั้นลงจริง จะไม่ใช้คำตอบนั้น แล้วลอง API ถัดไป
- **ย่อเหลือเท่าไหร่:** สองในสาม · ครึ่งหนึ่ง (ค่าเริ่มต้น) · หนึ่งในสาม
- **ทีละเอนทรี:** ปุ่ม ✨ **ให้ AI ย่อเนื้อหา** ใต้ช่องเนื้อหา (ปุ่มจะเด่นขึ้นเมื่อยาวเกิน 500 โทเคน)
  - ขึ้นกล่องให้ดูและแก้ก่อนกดใช้
  - เนื้อหาเดิมเก็บสำรองไว้ในเบราว์เซอร์ กด **เนื้อหาก่อนย่อ** เพื่อกู้คืนได้
- **ทั้งเล่ม:** เมนู ⋯ ของเล่ม → **ให้ AI ย่อเอนทรีที่ยาว**
  - เลือกได้ว่าจะย่อเอนทรีไหน ติ๊กไว้ให้แล้วเฉพาะที่ยาวเกิน 500 โทเคน
  - เห็นโทเคนก่อน/หลังของแต่ละตัว เปิดดูและแก้ได้ แล้วค่อยกดใช้

## สำรองข้อมูล

ก่อนส่วน ตรวจ & รวม เขียนทับเล่มเดิม จะสำรองไว้ใน IndexedDB ของเบราว์เซอร์ เก็บ 10 ฉบับล่าสุดต่อเล่ม หลังบันทึกกดปุ่ม **กู้เล่มเดิมคืน** ได้

สำรองนี้อยู่เฉพาะเบราว์เซอร์ที่ใช้ตอนบันทึก ส่วนการแก้ทีละเอนทรีในหน้า เล่ม บันทึกลงไฟล์ทันทีเหมือนหน้าของ ST ถ้าจะแก้เยอะ ดาวน์โหลด .json เก็บไว้ก่อนได้จากเมนู ⋯ ของเล่ม
