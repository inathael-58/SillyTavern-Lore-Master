# Lore Master — SillyTavern extension

**ตรวจ ซ่อม และรวม lorebook** โดยเฉพาะเล่มที่ import มาจากเว็บอื่น (JanitorAI ก่อน) ซึ่งไม่ได้เขียนมาเพื่อ ST เลยมีปัญหา เช่น ติดเทิร์นละหลายสิบเอนทรี ติดผิดเรื่อง หรือไม่ติดเลย

ใช้บนมือถือได้: เปิดเต็มจอ ปุ่มใหญ่ และอธิบายทุกข้อเป็นภาษาไทย

ตัวอย่างจากบอทบน JanitorAI ที่มี 3 เล่ม รวม 160 เอนทรี ทดสอบด้วยข้อความในแชท 2 ข้อความ:

| | ก่อนซ่อม | หลังซ่อม |
|---|---|---|
| เอนทรีที่ติด | 40 | 6 |
| โทเคน | ≈ 7,800 | ≈ 1,400 |

## ปัญหาที่แก้

- **ST import ไฟล์ของ JanitorAI ไม่ได้** ไฟล์ export ของ JanitorAI ไม่ใช่รูปแบบที่ ST อ่านได้ (ขึ้นว่า *Is not a valid world info file*) Lore Master แปลงให้เอง
- **ติดทีละหลายสิบเอนทรี** สาเหตุหลักคือ recursion: เนื้อหาของเอนทรีหนึ่งมีชื่อของเอนทรีอื่น พอติด 1 ตัว ST ก็ลากตัวอื่นตามมาเป็นทอด ๆ JanitorAI ไม่มีระบบนี้ คนทำบอทที่นั่นจึงไม่ได้เขียนเผื่อ
- **ติดผิดเรื่อง** คีย์เป็นคำทั่วไป (`park`, `coach`, `library`, `#11`) หรือคีย์ชนกัน เช่น นามสกุลของตัวร้ายไปตรงกับชื่อเพื่อนร่วมทีม
- **บอทเดียวมีหลายเล่ม** คนบน Janitor ชอบแยกเป็นหลายเล่ม Lore Master รวมเป็นเล่มเดียวให้ แล้วตั้งเป็นเล่มหลักของการ์ด เวลา export การ์ด เล่มนี้จะติดไปด้วย

## ติดตั้ง

Extensions → Install extension → วาง URL ของ repo นี้

## ใช้งาน

เปิดได้ 3 ทาง:
- กด **Import** ในหน้า World Info แล้วเลือกไฟล์ของ JanitorAI จะเปิด Lore Master ให้เอง ไฟล์ของ ST ยัง import ตามปกติ
- ปุ่มรูปหูฟังแพทย์ 🩺 ข้างปุ่ม Import ในหน้า World Info ถ้าเปิดเล่มไหนค้างไว้ในตัวแก้ไข จะเริ่มตรวจเล่มนั้นเลย
- พิมพ์ `/loremaster` (หรือ `/lm`) หรือไปที่ Extensions → Lore Master

มี 4 แท็บ:

1. **เลือกเล่ม** มี 3 ทาง: เลือกไฟล์ .json (หลายไฟล์พร้อมกันได้) · เลือกจากเล่มที่มีใน ST · กด **เล่มของ \<การ์ด\>** เพื่อดึงเล่มหลักกับเล่มเสริมทั้งหมดของการ์ดที่เปิดอยู่ ถ้าเลือกหลายเล่ม จะรวมเป็นเล่มเดียว
   - ไฟล์จากเว็บอื่นไม่ได้บอกว่าให้ใส่ตรงไหนใน prompt เลยต้องเลือกเอง: ก่อนข้อมูลตัวละคร (แนะนำ) · หลังข้อมูลตัวละคร · ในแชท @D4
2. **ตรวจ** แสดงปัญหาเรียงตามความด่วน แต่ละข้อบอกว่าทำไมถึงเป็นปัญหา และจะแก้อะไรบ้าง
   - ติ๊กเลือก/ไม่เลือกได้ทีละรายการ แล้วกด **ซ่อมข้อนี้** หรือ **ซ่อมทุกข้อที่ติ๊กไว้**
   - กด **ย้อน** ได้ทุกครั้ง
   - ถ้ามีแชทเปิดอยู่ จะบอกว่าข้อความล่าสุดทำให้เอนทรีติดกี่ตัว ทั้งก่อนซ่อมและตอนนี้
3. **ทดสอบ** พิมพ์หรือวางข้อความ ดูว่าเอนทรีไหนจะติดเพราะคีย์อะไร เทียบก่อนและหลังซ่อม ไม่เรียก API
4. **บันทึก**
   - บันทึกเป็นเล่มใหม่ หรือเขียนทับเล่มเดิม ถ้าเขียนทับ จะสำรองเล่มเดิมไว้ในเบราว์เซอร์ก่อน กู้คืนได้
   - ตั้งเป็น lorebook หลักของการ์ดได้ ถ้าการ์ดมีเล่มหลักอยู่แล้ว เล่มเดิมจะย้ายไปเป็นเล่มเสริม ไม่หายไปไหน และถอดเล่มที่รวมไปแล้วออกจากการ์ดได้ เนื้อหาเดียวกันจะได้ไม่ติดซ้ำ 2 ที่
   - จำกัดจำนวนเอนทรีต่อเทิร์น (ดูด้านล่าง)
   - ดาวน์โหลดเป็นไฟล์ .json ได้

จะยังไม่แก้ไฟล์จริงจนกว่าจะกดบันทึก

## สิ่งที่ตรวจ

| ปัญหา | ซ่อมยังไง |
|---|---|
| **คีย์ที่โผล่แทบทุกข้อความ**: ชื่อตัวละครหลัก (ทั้งชื่อเต็มและชื่อเดียว), `{{user}}` และคำที่อยู่ในเนื้อหาเกือบทุกเอนทรี ST ใส่ชื่อคนพูดไว้หน้าทุกข้อความ คีย์พวกนี้จึงติดทุกเทิร์น | ลบคีย์นั้น ถ้าเป็นคีย์เดียวที่มีอยู่ จะไม่ติ๊กไว้ให้ |
| **ลูกโซ่ recursion** บอกว่าติด 1 เอนทรีแล้วลากตามมาได้ถึงกี่ตัว และตัวไหนลากตัวไหน | เปิด *Prevent further recursion* ให้เอนทรีที่ลากตัวอื่น |
| **เรื่องเดียวกันอยู่ 2 ที่** เช่น "Marc Ellis" อยู่ทั้งเล่มทีมบาสและเล่ม NPC ตรวจเฉพาะข้ามเล่ม เพราะเอนทรีที่ชื่อคล้ายกันในเล่มเดียวกันมักตั้งใจแยกหัวข้อ | รวมเป็นเอนทรีเดียว: เอาเนื้อหามาต่อกัน และรวมคีย์ |
| **คีย์เป็นคำทั่วไป**: คำที่ขึ้นต้นด้วยตัวเล็ก ตัวเลข (`#11`) คีย์ 1–2 ตัวอักษร และคำอังกฤษที่ใช้บ่อย (`Park`, `Switch`, `Mom`) | ลบคีย์ ยังเหลือชื่อเต็มไว้ให้ติด |
| **คีย์ชนกับชื่อของเอนทรีอื่น** เช่น "Mercer" ของตัวร้ายไปติดตอนพูดถึง "Eli Mercer" | ติ๊กให้ลบเฉพาะที่เป็นนามสกุล ส่วนชื่อต้นให้เลือกเอง |
| **ติดตลอด (constant) มากเกินไป** | เปลี่ยนเป็นติดเมื่อเจอคีย์ เหลือตัวเล็กสุดไว้ 1 ตัว |
| **ไม่มีคีย์** เลยไม่มีวันติด | ใช้ชื่อเอนทรีเป็นคีย์ |
| **คีย์รูปแบบเพี้ยน** เช่น `"a, b"` อยู่ในช่องเดียว มีเครื่องหมายคำพูดติดมา หรือซ้ำกัน | แยกคีย์ ตัดเครื่องหมาย และลบตัวซ้ำ |
| **คำสั่งของเว็บอื่น** เช่น `@@depth` ของ RisuAI, `{{#if}}` หรือสคริปต์ทริกเกอร์ของ JanitorAI | ลบบรรทัด `@@` ให้ ส่วนที่เหลือบอกว่าต้องแก้เอง |
| **เอนทรียาวเกิน 700 โทเคน** และ **ไม่มีคีย์ภาษาไทย** | แจ้งให้รู้เท่านั้น ไม่ได้แก้ให้ |

ตัวทดสอบจำลองแบบที่ติดมากที่สุด: ไม่นับ probability, inclusion group และงบโทเคน ของจริงอาจติดน้อยกว่านี้ ส่วนนับโทเคนเป็นค่าประมาณ ถ้าอยากเห็นของจริงตอนเจน ใช้ [Lore Lens](https://github.com/inathael-58/SillyTavern-LoreLens)

## จำกัดจำนวนเอนทรีต่อเทิร์น

เปิดได้ตอนบันทึก หรือแก้ภายหลังใน Extensions → Lore Master

ถ้าเล่มนั้นติดเกินจำนวนที่ตั้ง จะตัดตัวที่ติดทีหลังทิ้งก่อน ST เรียงเอนทรีจาก order สูงไปต่ำ แล้วค่อยต่อด้วยตัวที่ติดจากลูกโซ่ ตัวที่ติดทีหลังจึงสำคัญน้อยที่สุด ส่วนเอนทรี constant จะไม่ถูกตัด

ระบบนี้ทำงานเฉพาะเครื่องที่ลง Lore Master เล่มที่ส่งต่อให้คนอื่นใช้ได้ตามปกติ

ต้องใช้ ST รุ่นที่มี event `WORLDINFO_SCAN_DONE`

## สำรองข้อมูล

ก่อนเขียนทับเล่มเดิม จะสำรองไว้ใน IndexedDB ของเบราว์เซอร์ เก็บ 10 ฉบับล่าสุดต่อเล่ม หลังบันทึกกดปุ่ม **กู้เล่มเดิมคืน** ได้

สำรองนี้อยู่เฉพาะเบราว์เซอร์ที่ใช้ตอนบันทึก

## แผนต่อไป

- **v0.2 ตัวแก้ไข lorebook สำหรับมือถือ**
  - รายการเอนทรีเป็นการ์ด กรองได้ (มีปัญหา / ติดตลอด / ไม่มีคีย์ไทย)
  - หน้าแก้แต่ละเอนทรีแบ่งหมวด: เนื้อหา · ติดเมื่อไหร่ · ใส่ตรงไหน · ขั้นสูง
  - ทุกช่องมีคำอธิบายภาษาไทย และแก้ทีละหลายเอนทรีได้
- **v0.3 คีย์ภาษาไทย**
  - ให้ AI เสนอคำทับศัพท์ ชื่อเล่น และคำแปล ตั้ง API ได้หลายตัวแบบ Memory Hub ให้โมเดลฟรีทำงานเล็ก ๆ แบบนี้ได้
  - ตรวจทุกคีย์ก่อนเพิ่ม และเตือนคีย์ไทยที่ไปติดกลางคำอื่น
  - **อภิธานชื่อเฉพาะ** ใช้ได้ 2 แบบ:
    - **คนที่ไม่ได้ลง Lore Master:** เก็บไว้ในเล่มเป็นเอนทรีธรรมดา เช่น `Cody = โคดี้` เอาไปแชร์ใช้ได้เลย
    - **คนที่ลง Lore Master:** ปิดเอนทรีนั้นตอนเล่น แล้วแทรกเฉพาะชื่อที่โผล่ในบทสนทนาช่วงนั้นแทน ประหยัดโทเคนกว่า
- **v0.4** ดึงสถิติจาก Lore Lens มาแสดงในตัวแก้ไข เช่น "ติด 48 จาก 50 เทิร์น" หรือ "ไม่เคยติดเลย"
