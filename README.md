# Lore Master — SillyTavern extension

**จัดการ lorebook แทนหน้า World Info ของ ST** ทำมาให้ใช้บนมือถือเป็นหลัก หน้าตาอ่านง่าย ช่องกรอกใหญ่ และอธิบายทุกช่องเป็นภาษาไทย ใช้ตัวนี้ตัวเดียวก็ไม่ต้องเปิดหน้า World Info ของ ST อีก

มี 3 ส่วน (แถบเมนูด้านล่าง):

- **เล่ม**: ดูทุกเล่ม เปิดแก้ทีละเอนทรี และผูกเล่มกับการ์ด แชท หรือ Global
- **ตรวจ & รวม**: นำเข้า lorebook จากเว็บอื่น (JanitorAI ก่อน) รวมหลายเล่มเป็นเล่มเดียว หาสาเหตุที่ติดทีละหลายสิบเอนทรีแล้วซ่อม
- **ตั้งค่า**: ค่าการสแกน World Info ของ ST อธิบายเป็นภาษาคน, ทางเข้า และหน้าตา

## ติดตั้ง

Extensions → Install extension → วาง URL ของ repo นี้

## เปิดได้หลายทาง

| ทาง | |
|---|---|
| **ปุ่ม World Info บนแถบด้านบน** (รูปหนังสือ) | เปิด Lore Master แทนหน้าเดิมของ ST |
| **ปุ่มลูกโลกในหน้าการ์ด** (Character Lore) | เปิดเล่มหลักของการ์ดนั้นเลย |
| **ปุ่ม Chat Lore** | เปิดเล่มที่ผูกกับแชทนี้ |
| **ปุ่มลอย** | ลากไปวางตรงไหนก็ได้ ปล่อยแล้วดูดติดขอบจอ เก็บเข้า Quick Dock ได้ (ใช้ "เลือกปุ่มบนจอ") |
| **เมนูไม้กายสิทธิ์ (Extensions)** → Lore Master | |
| **คำสั่ง** `/lore` หรือ `/lore ชื่อเล่ม` | เปิดเล่มนั้นเลย มีชื่อเรียกอื่นคือ `/loremaster` กับ `/lm` ใช้ทำปุ่มใน Quick Reply / Quick Dock ได้ |
| **ไอคอนบนแถบด้านบน** | ปิดไว้ตอนแรก เพราะปุ่ม World Info ทำหน้าที่นี้อยู่แล้ว เปิดได้ในหน้าตั้งค่า |
| **Extensions → Lore Master** | มีปุ่มเปิดตรงไปแต่ละส่วน |

- **กดปุ่ม Import ในหน้า World Info ของ ST แล้วเลือกไฟล์ของ JanitorAI** จะเปิดที่นี่ให้เอง เพราะ ST import ไฟล์แบบนี้ไม่ได้
- **ถ้าอยากใช้หน้าเดิมของ ST** ปิด "ใช้แทนหน้า World Info ของ ST" ในหน้าตั้งค่า หรือกด **เปิดหน้า World Info เดิมของ ST** ในหน้าเดียวกัน (กดปุ่มพร้อม Shift/Alt ก็ได้หน้าเดิม)
- **บนมือถือ** ปัดย้อนกลับหรือกดปุ่ม Back ของเครื่อง จะถอยกลับทีละหน้า ไม่ปิด ST

## เล่ม

**รายการเล่ม**
- ด้านบนคือเล่มที่ **ใช้อยู่ตอนนี้** กับแชทที่เปิด มีป้ายบอกว่าเป็น 💬 เล่มของแชท · 👤 เล่มหลักของการ์ด · 📎 เล่มเสริม · 🎭 Persona · 🌐 Global
- ทุกเล่มบอกจำนวนเอนทรี โทเคนรวม และจำนวนที่ติดตลอด
- ปุ่ม ⋯ ของแต่ละเล่ม:
  - ตรวจหาปัญหา
  - เปิด/ปิด Global
  - ตั้งเป็นเล่มหลักหรือเล่มเสริมของการ์ด
  - ผูกกับแชทนี้
  - เปลี่ยนชื่อ: ลิงก์ทุกที่ (Global การ์ด แชท persona) เปลี่ยนตามให้
  - ทำสำเนา · รวมกับเล่มอื่น · ดาวน์โหลด .json · ลบ
- ปุ่ม **+** มี 3 อย่าง: สร้างเล่มเปล่า · นำเข้าไฟล์ (ตรวจก่อนบันทึก) · รวมหลายเล่ม

**ในเล่ม**
- **ชิปด้านบน** แตะเพื่อผูก/ถอดเล่มนี้กับ Global การ์ด หรือแชทได้ทันที
- **ค้นหา** ทั้งชื่อ คีย์ และเนื้อหา
- **เรียง** ตามลำดับในเล่ม · ชื่อ · order · ความยาว
- **ตัวกรอง**: ติดเมื่อเจอคีย์ · ติดตลอด · ปิดอยู่ · มีคำเตือน · ไม่มีคีย์ไทย
- **การ์ดเอนทรี** มีแถบสีบอกสถานะ 🟢 เจอคีย์ · 🔵 ติดตลอด · ⚪ ปิด, คีย์, ตำแหน่ง, order, โทเคน, ⚠ คำเตือน และสวิตช์เปิด/ปิด
- **เลือกหลายรายการ** (ปุ่ม ☑ ที่หัวหน้า) แล้วทำทีเดียวได้: เปิด/ปิด · ติดตลอด/เจอคีย์ · ตำแหน่ง · order · กันลูกโซ่ · คัดลอก/ย้ายไปเล่มอื่น · ลบ

**แก้เอนทรี** บันทึกเองระหว่างพิมพ์ มีสถานะบอกที่หัวหน้า

| หมวด | |
|---|---|
| ชื่อ | ไว้ให้เราหาเจอ |
| ติดเมื่อไหร่ | เจอคีย์ / ติดตลอด / ปิด, คีย์เป็นชิป (Enter หรือ , เพื่อเพิ่ม), คีย์รองพร้อมเงื่อนไขเป็นภาษาคน, **บอกทันทีว่าข้อความล่าสุดในแชททำให้เอนทรีนี้ติดไหม** |
| คำเตือนคีย์ | ชื่อตัวละครหลัก (ติดทุกเทิร์น), ตัวเลข, สั้นเกิน, คำทั่วไป, คำไทยสั้นที่ไปติดกลางคำอื่น, regex ผิด |
| เนื้อหา | ช่องขยายตามข้อความ นับตัวอักษรและโทเคนด้วย tokenizer ของ ST |
| ใส่ตรงไหน | ทุกตำแหน่งพร้อมคำอธิบาย, ความลึกและบทบาท (@D), ชื่อ Outlet, order |
| ขั้นสูง | ความน่าจะเป็น · Inclusion group · Sticky/Cooldown/Delay · ลูกโซ่ · การสแกน (ความลึก ตัวพิมพ์ ทั้งคำ, สแกนในคำอธิบาย/persona/scenario) · ใช้เฉพาะบางตัวละคร · ทำงานเฉพาะตอน (swipe, continue …) · ไม่นับงบ · Vector · Automation ID |

ปุ่ม ˄ ˅ ที่หัวหน้าใช้ไปเอนทรีก่อน/ถัดไป ส่วน ⋯ มีทำสำเนา · เลื่อนขึ้น/ลง · คัดลอก/ย้ายไปเล่มอื่น · ลบ

## ตรวจ & รวม

สำหรับ lorebook ที่ import มาจากเว็บอื่นซึ่งไม่ได้เขียนมาเพื่อ ST เลยติดทีละหลายสิบเอนทรี ติดผิดเรื่อง หรือไม่ติดเลย

ตัวอย่างจากบอทบน JanitorAI ที่มี 3 เล่ม รวม 160 เอนทรี ทดสอบด้วยข้อความในแชท 2 ข้อความ:

| | ก่อนซ่อม | หลังซ่อม |
|---|---|---|
| เอนทรีที่ติด | 40 | 6 |
| โทเคน | ≈ 7,800 | ≈ 1,400 |

ทำเป็น 4 ขั้น:
1. **เลือกเล่ม** ไฟล์ .json (ของ ST, JanitorAI, character_book หรือการ์ด, หลายไฟล์ได้) · เล่มใน ST · เล่มทั้งหมดของการ์ดที่เปิดอยู่ ถ้าเลือกหลายเล่มจะรวมเป็นเล่มเดียว ไฟล์จากเว็บอื่นไม่บอกตำแหน่งใน prompt จะให้เลือกเอง
2. **ตรวจ** แสดงปัญหาเรียงตามความด่วน พร้อมเหตุผล ติ๊กเลือกได้ทีละรายการ แล้วกดซ่อมทีละข้อหรือทั้งหมด กดย้อนได้ ถ้ามีแชทเปิดอยู่ จะเทียบให้ดูว่าข้อความล่าสุดทำให้ติดกี่ตัว ก่อนซ่อมกับตอนนี้
3. **ทดสอบ** วางข้อความดูว่าอะไรติดเพราะคีย์ไหน เทียบก่อน/หลัง ไม่เรียก API
4. **บันทึก** เป็นเล่มใหม่หรือเขียนทับเล่มเดิม (สำรองไว้ก่อน) และทำได้อีก 3 อย่าง:
   - ตั้งเป็นเล่มหลักของการ์ด เวลา export การ์ด เล่มนี้จะติดไปด้วย คนที่ได้การ์ดไปใช้ได้เลยโดยไม่ต้องลง Lore Master
   - ถอดเล่มที่รวมไปแล้วออกจากการ์ด จะได้ไม่ติดซ้ำ 2 ที่
   - จำกัดจำนวนเอนทรีต่อเทิร์น

### สิ่งที่ตรวจ

| ปัญหา | ซ่อมยังไง |
|---|---|
| **คีย์ที่โผล่แทบทุกข้อความ**: ชื่อตัวละครหลัก (ทั้งชื่อเต็มและชื่อเดียว), `{{user}}` และคำที่อยู่ในเนื้อหาเกือบทุกเอนทรี ST ใส่ชื่อคนพูดไว้หน้าทุกข้อความ คีย์พวกนี้จึงติดทุกเทิร์น | ลบคีย์นั้น ถ้าเป็นคีย์เดียวที่มีอยู่ จะไม่ติ๊กไว้ให้ |
| **ลูกโซ่ recursion** บอกว่าติด 1 เอนทรีแล้วลากตามมาได้ถึงกี่ตัว และตัวไหนลากตัวไหน | เปิด *Prevent further recursion* ให้เอนทรีที่ลากตัวอื่น |
| **เรื่องเดียวกันอยู่ 2 ที่** เช่น "Marc Ellis" อยู่ทั้งเล่มทีมบาสและเล่ม NPC ตรวจเฉพาะข้ามเล่ม เพราะเอนทรีที่ชื่อคล้ายกันในเล่มเดียวกันมักตั้งใจแยกหัวข้อ | รวมเป็นเอนทรีเดียว: เอาเนื้อหามาต่อกัน และรวมคีย์ |
| **คีย์เป็นคำทั่วไป**: คำที่ขึ้นต้นด้วยตัวเล็ก ตัวเลข (`#11`) คีย์ 1–2 ตัวอักษร และคำอังกฤษที่ใช้บ่อย (`Park`, `Switch`, `Mom`) | ลบคีย์ ยังเหลือชื่อเต็มไว้ให้ติด |
| **คีย์ชนกับชื่อของเอนทรีอื่น** เช่น "Mercer" ของตัวร้ายไปติดตอนพูดถึง "Eli Mercer" | ติ๊กให้ลบเฉพาะที่เป็นนามสกุล ส่วนชื่อต้นให้เลือกเอง |
| **ติดตลอด (constant) มากเกินไป** | เปลี่ยนเป็นติดเมื่อเจอคีย์ เหลือตัวเล็กสุดไว้ 1 ตัว |
| **ไม่มีคีย์** เลยไม่มีวันติด | ใช้ชื่อเอนทรีเป็นคีย์ |
| **คีย์รูปแบบเพี้ยน** เช่น `"a, b"` อยู่ในช่องเดียว มีเครื่องหมายคำพูดติดมา หรือซ้ำกัน | แยกคีย์ ตัดเครื่องหมาย และลบตัวซ้ำ |
| **คำสั่งของเว็บอื่น** เช่น `@@depth` ของ RisuAI, `{{#if}}` หรือสคริปต์ทริกเกอร์ของ JanitorAI | ลบบรรทัด `@@` ให้ ส่วนที่เหลือบอกว่าต้องแก้เอง |
| **เอนทรียาวเกิน 700 โทเคน** และ **ไม่มีคีย์ภาษาไทย** | แจ้งให้รู้เท่านั้น ไม่ได้แก้ให้ |

ตัวทดสอบจำลองแบบที่ติดมากที่สุด: ไม่นับ probability, inclusion group และงบโทเคน ของจริงอาจติดน้อยกว่านี้ ส่วนนับโทเคนเป็นค่าประมาณ ถ้าอยากเห็นของจริงตอนเจน ใช้ [Lore Lens](https://github.com/inathael-58/SillyTavern-LoreLens)

## จำกัดจำนวนเอนทรีต่อเทิร์น

เปิดได้ตอนบันทึกในหน้า ตรวจ & รวม หรือตั้งภายหลังในหน้า **ตั้งค่า** ของ Lore Master

ถ้าเล่มนั้นติดเกินจำนวนที่ตั้ง จะตัดตัวที่ติดทีหลังทิ้งก่อน ST เรียงเอนทรีจาก order สูงไปต่ำ แล้วค่อยต่อด้วยตัวที่ติดจากลูกโซ่ ตัวที่ติดทีหลังจึงสำคัญน้อยที่สุด ส่วนเอนทรี constant จะไม่ถูกตัด

ระบบนี้ทำงานเฉพาะเครื่องที่ลง Lore Master เล่มที่ส่งต่อให้คนอื่นใช้ได้ตามปกติ

ต้องใช้ ST รุ่นที่มี event `WORLDINFO_SCAN_DONE`

## สำรองข้อมูล

ก่อนส่วน ตรวจ & รวม เขียนทับเล่มเดิม จะสำรองไว้ใน IndexedDB ของเบราว์เซอร์ เก็บ 10 ฉบับล่าสุดต่อเล่ม หลังบันทึกกดปุ่ม **กู้เล่มเดิมคืน** ได้

สำรองนี้อยู่เฉพาะเบราว์เซอร์ที่ใช้ตอนบันทึก ส่วนการแก้ทีละเอนทรีในหน้า เล่ม บันทึกลงไฟล์ทันทีเหมือนหน้าของ ST ถ้าจะแก้เยอะ ดาวน์โหลด .json เก็บไว้ก่อนได้จากเมนู ⋯ ของเล่ม

## แผนต่อไป

- **v0.3 คีย์ภาษาไทย**
  - ให้ AI เสนอคำทับศัพท์ ชื่อเล่น และคำแปล ตั้ง API ได้หลายตัวแบบ Memory Hub ให้โมเดลฟรีทำงานเล็ก ๆ แบบนี้ได้
  - ตรวจทุกคีย์ก่อนเพิ่ม และเตือนคีย์ไทยที่ไปติดกลางคำอื่น
  - **อภิธานชื่อเฉพาะ** ใช้ได้ 2 แบบ:
    - **คนที่ไม่ได้ลง Lore Master:** เก็บไว้ในเล่มเป็นเอนทรีธรรมดา เช่น `Cody = โคดี้` เอาไปแชร์ใช้ได้เลย
    - **คนที่ลง Lore Master:** ปิดเอนทรีนั้นตอนเล่น แล้วแทรกเฉพาะชื่อที่โผล่ในบทสนทนาช่วงนั้นแทน ประหยัดโทเคนกว่า
- **v0.4** ดึงสถิติจาก Lore Lens มาแสดงในตัวแก้ไข เช่น "ติด 48 จาก 50 เทิร์น" หรือ "ไม่เคยติดเลย"
